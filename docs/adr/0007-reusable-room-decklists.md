# Reusable room decklists

Each room participant owns private decklists stored in the room independently of any match, and can reuse them for rematches. Each participant in a new match selects a decklist and marks ready; any room participant can start when two to four participants are ready. Starting the match creates fresh card instances in each Match Player's Library, after which players shuffle and draw manually. Match state does not mutate the saved lists or expose their contents to opponents.
