# Solo practice Matches

_Superseded by [ADR-0016](0016-rules-automated-commander-and-practice.md)._

A Room Participant may start a one-player Match in any Room through a separate action shown only when they are the sole ready participant. This extends the two-to-four-player boundaries in ADR-0002 and ADR-0007 while preserving multiplayer starts and unanimous consent for replacing an active Match; other Room Participants can observe a Solo Match but only its Match Player can change it.
