# Automatic Battlefield groups for the interactive rules UI

The interactive UI for Rules-Automated Matches automatically arranges permanents in type-based Battlefield Groups, without manual placement. This favors predictable, readable Player Areas over a freely arranged tabletop; grouping uses current types with creature, planeswalker, battle, land, artifact, then enchantment precedence, and attached Auras and Equipment remain visually associated with their host. This supersedes ADR-0010's free-placement policy for this UI while retaining the distinction between presentation and gameplay state; layout must not change rules behavior.
