# Shared Battlefield layout is presentation state

The Match has one shared Battlefield Zone. Player Areas are presentation within that Zone, not separate Zones, and layout does not change gameplay state. In legacy Manual Matches, saved positions remain associated with their Player Areas. [ADR-0017](0017-automatic-battlefield-groups.md) defines the automatic grouping used by the Rules-Automated UI; old spatial data remains only for legacy compatibility.
