# Full catalog with staged rules coverage

The local card catalog contains the full Scryfall card pool, while executable card rules are added in stages, beginning with a mechanics-focused pool. All cards remain usable in manual matches; rules-automated matches initially use only cards whose behavior is supported. The long-term goal is automated rules support for every card, so catalog availability remains separate from rules coverage. Automated tests are required as mechanics are added so each supported rule can be validated.
