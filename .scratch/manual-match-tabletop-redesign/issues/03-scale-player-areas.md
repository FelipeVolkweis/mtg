# 03: Scale Player Areas to Solo, Three, and Four Players

**What to build:** The shared Battlefield adapts its Player Areas to the Match size while keeping each viewer's area nearest the bottom. Four players see a 2×2 table, three see two opponent areas above a wider local area, and a Solo Match uses the available table space.

**Blocked by:** 02: Shared Two-Player Areas.

**Status:** ready-for-agent

- [ ] Four-player Matches show four distinct Player Areas in a 2×2 arrangement, with consistent shared card placement for every viewer.
- [ ] Three-player Matches show two opponent areas above a wider local area; Solo Matches use one full Player Area without empty opponent spaces.
- [ ] Each viewer sees their own area nearest the bottom, and all Match Players remain identifiable by name and accent.
- [ ] A nonplaying Room Participant may observe a Solo Match but cannot change it.
- [ ] Browser-level checks cover all four supported Match sizes with empty and populated Battlefields.
